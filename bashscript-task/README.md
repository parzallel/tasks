

# اسکریپت راه‌اندازی Nginx در Ubuntu

این یک اسکریپت Bash است که به‌صورت خودکار کارهای زیر را انجام می‌دهد:

* نمایش وضعیت CPU و RAM سیستم
* گزارش میزان فضای دیسک
* نصب سرویس Nginx روی Ubuntu
* فعال‌سازی و اجرای سرویس
* ایجاد یک صفحه HTML ساده روی پورت 80
* بررسی وضعیت فعال بودن سرویس



## ⚙️ عملکرد اسکریپت

## 1️⃣ نمایش وضعیت منابع سیستم

اسکریپت اطلاعات زیر را نمایش می‌دهد:

* میانگین بار CPU با دستور `uptime`
* مشخصات پردازنده با `lscpu`
* میزان مصرف RAM با `free -h`
* میزان فضای دیسک با `df -h`



## 2️⃣ نصب و راه‌اندازی Nginx

* به‌روزرسانی لیست پکیج‌ها با `apt-get update`
* نصب nginx با `apt-get install nginx`
* فعال‌سازی سرویس برای اجرا در زمان بوت سیستم
* اجرای فوری سرویس



## 3️⃣ ایجاد صفحه HTML ساده

یک فایل HTML در مسیر پیش‌فرض nginx ساخته می‌شود:

```
/var/www/html/index.html
```

این صفحه از طریق آدرس زیر قابل مشاهده است:

```
http://localhost
```



## 4️⃣ بررسی وضعیت سرویس

در پایان، وضعیت nginx بررسی می‌شود;

اگر خروجی `NginX is Active and Running on Port 80`باشد، سرویس به‌درستی اجرا شده است.



## چالش ها :

- برای مدیریت خروجی `apt-get update` و `apt-get install` به /dev/null مشکل کوچکی وجود داشت که حل شد.
- برای ایجاد دسترسی قابل اجرا  فایل باید حتما executable باشد
